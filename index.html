QA Crawler

A personal tool that collects QA job postings from public Telegram channels and emails one digest a day.

Purpose

QA Crawler exists for a single reason: QA specialists follow many Telegram channels with job postings, and reading them all every day is noisy. The application watches those public channels, keeps only the relevant vacancies, and sends one compact email digest at the end of the day.

What the application does

  • Reads posts from public Telegram channels — the same pages anyone can open in a browser at t.me/s/<channel>.
  • Filters them by keywords, exclusions, and a relevance score.
  • Builds a single HTML digest and sends it to the owner's own mailbox through the Gmail API.
  • Stores a small local database to avoid sending the same vacancy twice.

Who uses it

This is a personal, single-user tool operated by its author. It is not a public service, has no sign-up, and is not offered to third parties.

How it runs

Everything happens on the owner's computer. There is no backend server, no cloud storage, and no analytics. The only network calls are: fetching public channel pages and calling the Gmail API to send the digest.

Data and privacy

The application reads public channel posts and uses the gmail.send scope only — it cannot read or modify mailbox contents. Details, including retention and deletion, are in the privacy policy.

Compliance. QA Crawler complies with the Google APIs Terms of Service and the Google API Services User Data Policy, including the Limited Use requirements. The application does not generate, process, or distribute AI-generated imagery of any kind, including non-consensual intimate imagery (NCII), and does not use Google APIs for such purposes.
